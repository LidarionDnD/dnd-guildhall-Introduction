# Chapter 1: Getting Started

This chapter guides you through the initial setup and basic usage of **DnD Guildhall**. You will learn the system prerequisites, explore the module's user interface, and create your very first adventuring guild.

---

## Chapter Overview

1. [**Installation & Requirements**](./installation.html)
   - System requirements (Foundry VTT V14, D&D 5.5e / `dnd5e`).
   - Installing via Manifest URL or module directory.
   - Enabling and initializing the module in your game world.

2. [**Interface Overview & Navigation**](./interface_tour.html)
   - The scene control toolbar button.
   - The Guilds Dashboard (`guildhall-overview`).
   - The Active Guild window (`guildhall-active`) with header and tab navigation.
   - The dedicated Foundry Quest Sidebar tab.

3. [**Creating & Managing Guilds**](./creating_guilds.html)
   - Step-by-step guide to creating new guilds.
   - Setting guild banners, adjusting image positioning, and renaming guilds.
   - Configuring player visibility and permissions.
   - Safely deleting guilds and associated data.

---

> **Game Master Tip:**
> You can create and manage unlimited independent guilds in a single game world. Each guild operates with its own banner, member roster, quest board, and unique regulations.
